## 2024-03-24 - Python Data Object Memory Optimization
**Learning:** High-traffic data objects like `DepartureInfo`, `TripUpdate`, `VehiclePosition`, `ServiceAlert`, `RouteInfo`, and `StopInfo` instantiated by the thousands during realtime updates suffer from significant overhead from `__dict__`. Using Python 3.10+ `@dataclass(slots=True)` reduces the memory footprint per instance from ~344 bytes to ~96 bytes. The `ScheduledDeparture` class in `gtfs_schedule.py`, which is not a dataclass, can use standard class `__slots__` to achieve an approximate 67% reduction in memory usage per object (from 344 bytes to 112 bytes).
**Action:** When adding or maintaining data objects that represent frequent transit data points, use `@dataclass(slots=True)` or `__slots__` explicitly to avoid memory bloat.
